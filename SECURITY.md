# Security

Please report security problems privately, not in a public issue: use
**Report a vulnerability** on this repository's
[Security tab](https://github.com/pley-media-server/pley-homeassistant/security).
I'll reply there, and publish a fix and an advisory once it's resolved.

Security fixes go into the latest version.

The integration keeps a sign-in to your Pley server, which can see what
plays on your devices, control them and, for an administrator, stop
anyone's stream. Reports about anything that could leak that sign-in, send
it to a server other than yours, or let someone else control your devices
are especially welcome. Problems in the Pley server itself go to
[Pley's own security policy](https://github.com/pley-media-server/pley/security/policy).
