# <img src="https://raw.githubusercontent.com/pley-media-server/pley-homeassistant/master/custom_components/pley/brand/icon.png" alt="Pley" width="50" height="50"/> Pley for Home Assistant

Brings the devices playing from your [Pley](https://github.com/pley-media-server/pley)
media server into Home Assistant: each TV and app shows what's playing as a
media player, which your dashboards and automations can pause, stop or
start a title, playlist or channel on. It's in development, and not ready
to install yet.
